# n8n error-handling study: analysis scripts

The scripts behind [n8n Error Handling: Five Signals in Public Workflow Files](https://noderecipe.com/n8n-error-handling-data).

`scripts/2026-09-12/` holds the eight scripts exactly as they were run on 12 and 13 September 2026
to produce the published counts, against `Zie619/n8n-workflows` at commit
`94007c1445d9258a7da116646b79473e7c7c3282`. They have not been edited since.
